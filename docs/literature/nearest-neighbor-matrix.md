# 最近邻矩阵

目的：把"经验共享"拆成互不相同的机制族，避免把所有共享都称作直接近邻，也避免因为强调"失败"就宣称新颖。

距离定义（**相对 PitfallRelay 的目标陈述**，不是相对"经验共享"这个大类）：
- **近**：共享同一个机制部件，且只需替换一个模块就能得到本项目的设定。
- **中**：共享问题的一部分（例如同样执行期不更新参数），但目标或表征不同。
- **远**：只在动机层相似。

**这一族没有覆盖的**：执行期传递、失败语义、学习式经验编码、接收方级适用性。

## 结论：四档证据分类（第二轮重写）

第一轮用"已被占 / 仍空着"二分，这是**存在性结论**，超出了题录级与摘要级证据能支持的范围。现改为四档：

### 档 1：正文核实，确有实现

| 命题 | 工作 | 证据定位 |
| --- | --- | --- |
| agent 之间可以共享经验 | Tan 1993（3 种共享对象） | 摘要级 |
| 训练期共享全部轨迹可加速稀疏奖励学习 | SEAC 2020 | 正文 |
| 用绝对 TD 误差筛选要共享的转移，带宽 1%–10% | SUPER 2023 | 正文 |
| 选择性共享**在特定任务上**优于全共享；在另一些任务上全共享更好 | SUPER 2023（Pursuit/Battle vs Adversarial Pursuit） | 正文 |
| 学习式共享记忆 + 读写门控 + 执行期读取 + 执行期不更新参数 | Pesce & Montana 2020 | 正文 |
| 记忆是逐 episode 重置、agent 顺序读写、critic 不接收记忆 | Pesce & Montana 2020 | 正文 |
| 跨局上下文 + 执行期无梯度 + 多智能体 | CooT 2026 | 正文 |
| 失败 = 过早终止；检索相似失败并**重新排序候选动作**；不从失败直接更新策略 | FEMA 2026 | 正文 |
| 不安全状态记忆 + 核密度伪计数构造内在代价 | MICE 2025 | 正文 |
| 跨 agent 经验库；成功与失败轨迹都入库；相似度 + 工具兼容性检索；计划一致性门控 | Agent KB 2025 | 正文 |
| 局部/全局记忆；Wilson 下界提升；按接收方状态与决策阶段条件化检索；显式存失败诊断与修复 | MemCo 2026 | 正文 |
| 接收方用**自己的 Q^i** TD 误差对邻居打分的经验做二次过滤（训练期、同构） | INSPIRE, Mach Learn 115:95 (2026) | 正文 |
| 有序对 i←j 的共享比例由观测 L2 + 策略 TV 距离 + 未学习度熵决定；固定比例共享会造成暂时退化 | Hayashida 2025 | 正文 |
| 逐学生、逐状态的建议门控（策略相似度 + CE 阈值）；全文未出现 negative transfer 指标 | CMU-RI-TR-25-11 (2025) | 正文 |
| CBR 只存正例（r_t > 0），相似度 = 共享 VQ code 比例，复用时不更新参数 | Atzeni et al. ICLR 2022 | 正文 |
| state-action 谓词规则 + 屏蔽；规则由人类/预言机 MAE 给；**规则可在同构 agent 间共享** | Shperberg, PMLR v199 (2022) | 正文 |
| 2 bit 的 receiver-conditioned action-value 消息；比特、FLOPs、训练时间三项同时报告 | RAVEN (2609.37566, 2026) | 正文 |
| distortion = 接收方 value loss，约束 2 bit/channel use | Mostaani et al. (2005.14220) | 正文 |
| 理论：最优消息是**接收方 advantage** 的统计量，固定 2.000 bit/decision | Emergence, Not Bandwidth (2609.34373) | 正文 |
| 执行期、用其他 agent 的历史结果（排除自身，LOAO）给经验打分 | XferAgent (2610.19581, 2026) | 正文 |
| 通信价值 = 接收方不确定性下降 | T2MAC, AAAI-24 | 正文 |

### 档 2：已读正文，但该文**未描述**某机制

- Pesce & Montana：正文未描述"agent j 的写入通过 agent i 的损失回传梯度"；也未描述 detach。**这不等于该路径不存在**。
- CooT：正文未把失败作为监督类别；上下文是否含伙伴观测，§4.3 与 §4.4 表述有歧义。
- FEMA：正文未给出 D_i 的聚合公式；未说明真机 seed 数。
- MICE：正文未描述执行期是否查询记忆。
- Agent KB：正文未定义失败标签体系；无 seed 与方差报告。
- MemCo：正文未说明适用性判断是否可学习（实现上是启发式打分 + 硬过滤）。

### 档 3：本次检索（截至 2026-10-29）未发现

- 同时满足「以发送方失败为对象 / 用接收方后续结果校准 / 执行期无梯度 / 异构并报告逐接收方负迁移」的工作。
- 把"发送方失败严重程度"作为适用性**负信号**的机制（现有 sender TD 误差全部是"有用性"的正代理）。
- failure-specific 的 accept/reject 分类器或适用性校准指标。
- 跨 agent 失败经验迁移的 held-out related-situation benchmark。
- 在非对称/异构设定下专门测量 **failure message** 负迁移的工作。
- 以"失败经验"为消息内容、同时报告 bit/byte 预算的工作。
- MARL 执行期 kNN/向量库检索的时延或索引存储成本报告。
- 自动产出符号化"条件—操作—后果"且无需人工标注的工作。

> 以上均为检索性陈述。`search-log.md` 已记录两轮检索范围与未覆盖处。

### 最危险的近邻（第二轮重新排序）

1. **MemCo（2026）**：跨 agent 共享 + 显式失败记录 + 按接收方状态/决策阶段条件化检索 + 执行期。虽是 LLM 文本路线、适用性为启发式，但"接收方条件化"与"失败入库"都已实做。
2. **INSPIRE（2026）**：接收方用自己的 Q^i 参与经验筛选，训练期、同构。它把"接收方信号参与经验价值判断"变成既有实现。
3. **CooT（ICML 2026）**：部署形态完全重合，但学习信号是专家最优动作监督，不是自身失败后果。
4. **FEMA（2026）**：失败→记忆→检索→改变动作的闭环在单智能体已完成；阈值与候选动作数消融给出了工程边界。

RAVEN 在问题 C 上是必须对照的上界（2 bit 接收方相关消息），但对象是当前协作价值而非失败经验。
