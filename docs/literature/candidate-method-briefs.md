# 候选方法草案（3 份，均非已批准架构）

这三份草案对应三个并列的技术问题，**不构成一条流水线**，也不预设贡献是"接收方门控"。任何一份单独成立都有意义；同时做需要更大的实验预算。

每份包含：候选问题定义 / 输入可见条件 / 关键机制与训练目标 / 最小必要基线 / 可区分预测与否定条件 / 工程与计算风险。

---

## 草案 A：无标注的失败分解——从"终止"到"条件—操作—后果"

### 问题定义

给定一条以不良后果结束的轨迹片段，学到一个分解：**在什么条件下、执行了什么操作、导致了什么后果**，且不需要人工标注失败、不需要反事实模拟器。

### 输入可见条件

- 执行期与训练期一致：只用该 agent 自己能观测到的量（观测、动作、奖励、终止标志）。
- 不使用全局状态、不使用队友私有信息，除非显式声明为训练期特权并单独评估。

### 关键机制与训练目标

三种候选实现，按假设强度递增：

1. **弱版（可立即做）**：以终止前 K 步为窗口，用对比学习把"导致终止的状态-动作对"与"同轨迹中更早的状态-动作对"区分开。目标函数是二分类或 triplet，标签来自时间顺序，不来自人工。
   - 理论前提：越靠近终止越相关。这个假设很强，且容易被"提前很久就已注定失败"的情形推翻。
2. **中版**：用回报分解（per-step advantage 或 return-to-go 差）给窗口内每一步打分，取贡献最大的若干步作为"操作"。
   - 理论前提：回报是可分解的、且优势估计足够准。需要 value 网络，训练不稳定。
3. **强版**：引入一个显式的"后果预测头"，输入（条件表征, 操作表征），预测是否导致失败；用失败与非失败片段做监督。
   - 需要定义"条件"与"操作"的切分粒度，这是设计选择，不是学习出来的。

### 最小必要基线

- 无记忆 / 无经验传递。
- 只用终止标志的最近一次失败（FEMA 式检索，ε 阈值）。
- 随机取窗口内状态-动作对。
- 只传当前观测。

### 可区分预测与否定条件

- **预测**：若分解有效，接收方在"同一条件、不同实例"上的重复失败率下降幅度，应大于"同一后果、不同条件"的下降幅度。
- **否定**：若接收方收益在"随机状态-动作对"基线上没有显著超出，则分解没有产生可用信息，只是增加了一个检索通道。

### 工程与计算风险

- 终止前 K 步的窗口长度是敏感超参（FEMA 的记忆刷新频率 M 与阈值 ε 都被证明敏感）。
- 回报分解需要 value 网络，训练方差大。
- 归因的可识别性问题无法用工程手段绕过；如果任务里失败前有多种路径，分解会不稳定。

## 草案 B：用"后果等价性"替代"状态相似度"做适用性判断

### 问题定义

接收方判断一条来自他人的失败经验是否适用于自己，依据不是"我们的状态像不像"，而是"**如果我们照做，会不会得到同样的后果**"。

### 输入可见条件

- 发送方只暴露经验表征与（可选的）其当时可观测信息。
- 接收方只能用自己的观测与可用动作查询经验库；不得读取发送方的完整轨迹。
- 执行期不更新参数。

### 关键机制与训练目标

1. 学习一个**后果条件化的经验编码** z = E(条件, 操作, 后果)。
2. 学习一个**接收方侧适用性打分** a = A(z, 接收方当前情境)，训练信号是"用了这条经验后，接收方在该情境的失败概率是否下降"。
3. 端到端梯度：发送方编码器 E 通过 A 与接收方决策损失获得梯度（若可行）。

理论前提：存在一个跨 agent 共享的"后果等价"空间——即不同 agent、不同状态但相同因果结构的情形会被映射到相近的 z。**这个假设本身是可证伪的**。

### 最小必要基线

按"用到多少接收方信息"分五级，**逐级都要打赢**，否则不成立：

1. 发送方 TD 误差筛选（SUPER）。
2. 成对相似度（Hayashida：观测 L2 + 策略 TV + 未学习度熵）。
3. 接收方本地 TD 误差二次过滤（INSPIRE）。
4. 接收方不确定性下降（T2MAC）。
5. 接收方历史结果（XferAgent 的 leave-one-agent-out）。

另外必须有：广播全部失败、打乱配对的失败消息（同比特、无关内容）、过期失败消息、以及**学习式状态相似度但不含后果**。

### 可区分预测与否定条件

- **预测 1**：在角色/观测不对称的任务里，后果等价性的 AUC 高于状态相似度。
- **预测 2**：差距随"发送方与接收方情境的状态相似度低但因果结构相同"的比例增大而扩大。
- **否定**：若在一个**刻意构造"状态不像但后果相同"**的探针任务里，后果等价性不优于状态相似度，则该假设不成立，应退回相似度基线。
- **否定 2**：若把 z 换成随机投影后性能不降，说明编码没有学到可迁移结构。

### 工程与计算风险

- 跨 agent 梯度路径需要自定义损失；在 BenchMARL 这类按 group 组织的框架里，很容易在无意中 detach 而表面上仍能跑。
- 执行期需要一次前向 + 一次检索；时延从未被文献报告，必须自测。
- 若发送方与接收方共用编码器，可能退化成"共享策略"，需要显式隔离。

## 草案 C：每比特决策收益——把"高效"变成可测的量

### 问题定义

给出一个评测协议，回答"这条经验值多少比特、带来多少决策改进"，而不是只报告"带宽 5%"或"样本效率 +33%"。

### 输入可见条件

不涉及新机制，只约束实验：消息必须可序列化到字节、可被截断、可被随机替换。

### 关键机制与训练目标

1. 定义消息的最小可序列化单元（浮点截断位数、量化级数、词表大小），使"比特数"可计算。
2. 构造**同比特不同内容**的四联对照：真实失败消息 / 等长随机消息 / 等长当前观测消息 / 过期失败消息。
3. 报告四个量纲的分离曲线：比特—收益、频次—收益、时延—收益、样本步—收益。
4. **语义对齐用任务价值失真**，不用重建误差或纯 entropy：借 Mostaani 的 `|V*(s) − V*(h(s))|` 或 RAVEN 的接收方 context 内 action-value 失真。
5. 必须报告**实测**消耗，而不是目标值——ETCNet 目标 50% 发送概率实测只有 46%。

### 最小必要基线

- 无消息。
- 同比特随机消息（下界）。
- 同比特当前观测消息（**最关键**：如果它打平失败消息，说明失败没有额外信息）。
- 同内容不压缩（比特上界）。
- 全量无压缩（信息上界）。

### 可区分预测与否定条件

- **预测**：失败消息相对等比特观测消息的收益，只在"接收方无法从当前观测直接看出风险"时出现。
- **否定**：若在观测里加一个位置/状态标记就能达到同等效果，则任务与机制都不成立（对应 research-brief 的 decision gate）。
- **否定 2**：若收益曲线对消息内容不敏感（随机消息也有同样曲线），说明测到的是正则化效应而非信息传递。

### 工程与计算风险

- 量化会改变消息分布，需要重新训练或至少校准。
- 时延测量依赖硬件与实现，跨机器不可比，必须报告测量条件。
- 这套协议本身不产生算法贡献，但它是其余两项能否被解释的前提。

## 三份草案的取舍

| | 科学新意上限 | 工程风险 | 最低成本 | 失败时的退路 |
| --- | --- | --- | --- | --- |
| A 失败分解 | 中（但容易变成特征工程） | 中 | 低 | 退回 FEMA 式检索基线 |
| B 后果等价性 | 中-高（假设可证伪） | 高（梯度路径） | 中 | 退回相似度基线，仍可发表为负结果 |
| C 评测协议 | 低（方法论） | 低 | 低 | 本身就是可交付的对照实验 |

**不给出"应该选哪个"的结论**——这取决于用户对"机制贡献 vs 评测贡献"的偏好，以及是否愿意承担跨 agent 梯度的工程风险。
