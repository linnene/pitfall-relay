## 记忆结构

**局部记忆** $M_i^l=[G_i^l, \mathcal P_i^l, \mathcal E_i^l, \mathcal R_i^l]$（§3.3）：

- $G_i^l$：归一化状态/动作/反馈节点的合并图，是结构索引，不是可回放的 episode。
- $\mathcal P_i^l$：模式记录，覆盖 "workflows, action preconditions, repairs, and failures"。
- $\mathcal E_i^l$：可操作知识，"state–action–outcome relations"（§B.2.3）。
- $\mathcal R_i^l$：具体案例与反思，含 "episode-specific examples, failure diagnoses, and recoveries"。

**全局记忆** $M^g$ 只存提升后的抽象记录，每个抽象键一条，字段为：

> "record type, applicability conditions, action sequence or relation, and outcome"（§3.4）

## 提升准则（学习信号）

- 按类型 + 归一化内容归并 → 固定类型过滤（排除不完整/低信息）→ **按 episode 去重**的证据计数。
- 分数用单侧 Wilson 下界：s = n⁺ + n⁻，ρ⁺ = n⁺/max(s,1)，α = 0.05，**λ = 0.35**。
- 同一 episode 内重复出现最多算一票；"contradiction takes precedence"（§B.2.4）。
- 证据变化时重新评估，不再达标就删除。

**注意**：这是统计置信下界，不是学出来的模型；失败以负证据 n⁻ 的形式进入同一套计数。

## 检索（这是与本课题最相关的部分）

- 查询 = 目标 + 当前观测 + 可用动作 + 过往交互历史（§3.5）。
- 局部与全局分开检索，各 k = 5。
- 打分 r(m,q) = r_x + r_p + r_g：状态/动作匹配、任务进度或**决策阶段**匹配、目标相关对象/工具角色匹配。
- **适用性是硬过滤**：条件与当前状态矛盾、或动作不在可用集合中，直接排除；过期或软冲突的局部信息降权。
- 检索结果按角色组装为 grounding / workflow guidance / reflection 三类。

**对问题 B 的意义**：这是**执行期、按接收方状态与决策阶段条件化**的适用性判断，且显式存失败。但判断是启发式打分 + 硬过滤，**不是以接收方损失为目标的学出来的判断**。

## 证据

- 基线（§4）：ICL、A-Mem、MemRL、MemSkill、G-Memory。
- 骨干：Qwen3-4B、GPT-4o-mini、Qwen3-32B；FEVER 另用 Claude-Haiku-4.5、Gemini-2.5-flash-lite、DeepSeek-v4-flash。
- **3 runs，mean ± std**；未列 seed 值。
- 局限（Limitations）：依赖初始交互轨迹（冷启动）；只测文本与符号环境。

## 与本课题的关系

- **相同点**：跨 agent 经验共享 + 显式失败记录 + 执行期 + 按接收方条件化。
- **关键差别**：
  - LLM 文本/符号路线，记忆是结构化记录不是神经表征；
  - 适用性 = 规则匹配 + 硬过滤，无可学习参数；
  - 无通信预算、无发送方权限模型；
  - 不测"相关但不相同情境"的受控泛化。
- **危险等级**：**最高**。它把"接收方条件化"从"空着"变成"已有启发式实现"，直接压缩第一轮的核心主张。
- **可复用**：Wilson 下界提升准则（可作为"经验条目何时值得共享"的统计基线）；三通道打分（状态/阶段/目标）作为启发式上限；硬过滤作为负迁移防护。
