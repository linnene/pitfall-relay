## 机制

- **经验收集**：在训练任务集上自主收集轨迹，存入经验池（不更新参数）。
- **知识抽取**：用 LLM 从轨迹中抽取自然语言 insight，维护操作为 ADD / UPVOTE / DOWNVOTE / EDIT，重要性计数控制存活（新规则计数 2，降到 0 删除）。
- **使用阶段**：推理时把存活的 insight 拼进 system prompt；再按任务相似度嵌入检索 top-k 成功轨迹作为 few-shot。
- **执行期参数更新**：否。
- **失败**：成功与失败轨迹都用于抽取 insight（"Learning from Successes and Failures"是章节标题级别的表述）。
- **跨任务**：经验池跨任务；论文明确区分 Reflexion（任务内重试）与 ExpeL（跨任务、部署时不重试）。

## 证据（待核数值）

- ALFWorld：ReAct 40% → 59%。
- HotpotQA：单次尝试达到 Reflexion 多次重试的水平。
- 跨域：HotpotQA 的 insight 迁移到 FEVER，63% → 70%。
- ExpeL + Reflexion 叠加：ALFWorld 59% → 64.2%。

## 与本课题的关系

- **相同点**：经验→可复用知识→跨情境复用，且不更新参数。
- **关键差别**：单 agent；自然语言 insight 而非神经表征；无发送方/接收方；无预算；相似度用嵌入检索。
- **可能致命重叠**：高——**但恰好界定了本项目的存在理由**：如果坚持神经表征，必须论证它在"相关但不相同情境"上优于自然语言 insight；否则直接用 ExpeL 更省事。
- **可复用**：ADD/UPVOTE/DOWNVOTE/EDIT 这种"经验条目生命周期"设计，可作为神经记忆的遗忘/置信度机制的对照。
