## 机制

- **记忆内容**：每个 agent 维护一个分层有向图，节点键是 afterstate（观测 o 与 off-beat 动作 ũ 的组合）；连续键用 SimHash 离散化。节点存访问计数、前驱/后继指针；子图按离散化回合回报索引。
- **是否跨 agent 共享**：**不共享**。每个 agent 有自己的图集 Φ_i；团队共享的是奖励，不是记忆。个体记忆中发现的 pivot 时间步会被合并用于信用分配。
- **跨局/遗忘/触发**：图跨多条轨迹累积访问计数与路径；检索时在采样的回合内找 pivot。无显式遗忘机制。
- **使用阶段**：训练（集中训练时从 replay 采样并做 TD 更新）；执行期用学好的策略，不更新参数。
- **失败定义**：无。
- **学习目标**：非参数记忆 + 标准 TD 损失（配合重分配奖励），没有学习式经验编码器。

## 证据

- **任务/基线**：Stag-Hunter、Quarry、Afforestation、SMAC 2m_vs_1z；基线 QMIX、VDN、IQL、QTRAN、QPLEX、EMC、n-step、TD(λ)、MAVEN、RMIX。
- **seed**：10 seeds。
- **结果要点**：Stag-Hunter 上 IQL/VDN 无 LeGEM 时为 0；QMIX-LeGEM 超过 QPLEX 与 MAVEN；n-step 即使 n=15 也失败。
- **泛化**：无 held-out 泛化实验。
- **负迁移**：未测。RMIX 在其实验中失败，属于基线失效而非负迁移分析。
- **算力**：未报告。
- **代码**：正文未给本方法仓库（提及 PyMARL 与公开基线）。

## 与本课题的关系

- **相同点**：多智能体 + 跨局记忆 + 检索 + 执行期用学好的策略。
- **关键差别**：记忆私有且不传递；键是"状态-动作"而非"后果"；无失败语义；无接收方适用性；记忆检索用于信用分配而非避免重犯。
- **可能致命重叠**：中。若 PitfallRelay 的机制被概括为"跨局存经历、按相似性检索"，LeGEM 已经在 MARL 里做了（只是不跨 agent）。
- **可复用**：10 seeds 的实验规范；afterstate 键与分层图作为"检索粒度"的对照实现。
