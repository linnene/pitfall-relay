## 机制

- **共享内容**：一个尺寸 M=200 的共享记忆向量 m；写入向量 m' 被称为"通信信道的内容本身"。
- **读**：r_i = m ⊙ k_i，门控 k_i = σ(W^k[e_i, h_i, m])，其中 e_i 是自身观测编码。
- **写**：候选 c_i = tanh(W^c[e_i, m])，输入门 g_i、遗忘门 f_i 均由 [e_i, m] 得到，m' = g_i⊙c_i + f_i⊙m。
- **使用阶段**：训练与执行都用；执行期只有学好的 actor 在动作，**记忆内容会更新但网络参数不更新**。
- **发送方信息**：自身观测经编码器 e_i；接收方可以读到全队写入的共享记忆。
- **接收方权限**：所有 agent 共享同一记忆，通过各自的门控取不同读向量——即接收方可选择性地"关注"，但不按接收方定制发送内容。
- **失败定义**：无。
- **记忆范围/遗忘/触发**：记忆在时间步上累积，写门控决定写入量；**不跨 episode 持久化**，episode 重置即清空（依据：作为 MDP 内状态处理）。
- **编码器/目标**：编码器 + 读门控 + 写门控，端到端用 DDPG 训练；通信表征没有单独的学习目标。
- **跨 agent 梯度（第二轮正文核实）**：论文称所有策略参数端到端由 actor-critic 更新；但**已读正文没有描述 agent j 的写入通过 agent i 的损失回传梯度**。集中式 critic 接收全体观测与动作，**不接收记忆**；记忆每个 episode 重置；agent 在同一时间步内**顺序**读写，后一个 agent 看到更新后的记忆。正文**也没有**显式 detach/stop-gradient 说明。
  - 准确表述：该公开正文**未描述**跨 agent 的写→读梯度路径；**不能据此断言该路径不存在**。本课题若要主张这一点，必须自行实现并验证梯度范数。

## 证据

- **任务**：六个 2D 导航任务（Cooperative Navigation 及其部分可观测、同步、顺序、交换变体，Waterworld），主实验 2 agents，补充最多 6 agents。
- **基线**：MADDPG、MA-MADDPG、CommNet、MAAC（Waterworld 无 MAAC，因离散动作）。
- **泛化**：无 held-out 实例/任务泛化实验。
- **负迁移**：未测。只做了信道污染（corruption）鲁棒性分析与模块消融。
- **seed**：正文未给出明确 seed 数（仅说补充材料考察随机种子鲁棒性）。
- **算力**：未报告。
- **代码**：正文未给代码链接，仅视频。

## 与本课题的关系

- **相同点**：**机制层面最接近**——学习式共享记忆、读/写门控、执行期读取、执行期不更新参数。
- **关键差别**：记忆内容是"当前观测的共享世界表征"，不是"一次失败交互的后果"；没有发送方/接收方的角色区分；没有跨局保留；没有适用性判断；没有负迁移评估。
- **可能致命重叠**：高。若 PitfallRelay 的表述是"学习一个共享记忆并让队友在执行期读它"，会被直接视为该文的复刻。
- **可复用**：读/写门控结构；"执行期只更新记忆、不更新参数"的部署范式；信道污染作为消息可信度的对照实验。
- **必须补的对照**：若不共享失败，只共享当前观测表征，性能差多少。
